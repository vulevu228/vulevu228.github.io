About

I'm an Information Engineering student at HAW Hamburg, entering my sixth semester, with coursework grounded in database systems and low-level engineering. Alongside my studies, I design and build end-to-end data pipelines in Python that collect real-world data on a schedule and turn it into a Power BI report, a searchable site, or a forecasting model.

I've lived and studied independently abroad for eight years, which has shaped how I approach my work: methodically, with an emphasis on data accuracy and reliable, unattended automation. I'm particularly interested in problems at the intersection of hardware and data.

OpenSkyFlightTracker Collecting data

Every aircraft in the sky, worldwide, every five minutes

An Azure Functions timer authenticates to the OpenSky Network with OAuth2 and saves a global snapshot of 10,000+ aircraft every five minutes. Raw positions land in daily files in Azure Blob Storage, next to a compact per-country summary built for Power BI. Retries ride out API hiccups, and Application Insights emails an alert if a run ever fails.

PythonAzure FunctionsBlob StorageApplication InsightsOAuth2
Repository private while data collects · dashboard to follow
AISShipTracker Collecting data

Ships at sea around the world, sampled every five minutes

An Azure Function opens a live AIS stream every five minutes, listens for a minute and keeps the latest position of every vessel it hears — about 7,000 ships per window — along with ship details such as type, destination and size. Daily files in Azure Blob Storage, with a per-window summary for Power BI.

PythonWebSocketsasyncioAzure FunctionsBlob Storage
Repository private while data collects · dashboard to follow
